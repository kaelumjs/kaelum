## Get started in three steps

<Steps>

1. **Scaffold a project** with the interactive CLI.

   ```bash
   npx kaelum create my-app
   cd my-app
   npm install
   ```

2. **Configure your app** with one config object.

   ```js
   const app = require("kaelum")();

   app.setConfig({
     cors: true,
     helmet: true,
     logs: "dev",
     static: "public",
   });
   ```

3. **Add routes and start the server.**

   ```js
   app.apiRoute("users", {
     get: (req, res) => res.json([]),
     post: (req, res) => res.status(201).json(req.body),
     "/:id": {
       get: (req, res) => res.json({ id: req.params.id }),
       delete: (req, res) => res.status(204).send(),
     },
   });

   app.healthCheck();
   app.useErrorHandler();
   app.start(3000);
   ```

</Steps>

## Frequently asked questions

<details>
<summary>What is Kaelum?</summary>

Kaelum is a minimalist Node.js framework built on top of Express. It removes
the boilerplate of body parsing, CORS, Helmet and route registration so you can
focus on business logic.

</details>

<details>
<summary>Do I need to know Express?</summary>

Not necessarily, but everything you know about Express still applies. You can
mix Kaelum helpers with any Express middleware.

</details>

<details>
<summary>How do I install Kaelum?</summary>

Run `npx kaelum create my-app` to scaffold a new project, or
`npm install kaelum` to add it to an existing one. Node.js 24.22.1+ is
required.

</details>

<details>
<summary>Can I use my own Express middleware?</summary>

Yes. The Kaelum app instance is a standard Express app, so `app.use()` and any
Express-compatible middleware work alongside Kaelum helpers.

</details>

<details>
<summary>Where can I get help or report a bug?</summary>

Open an issue on [GitHub](https://github.com/kaelumjs/kaelum/issues) with a
minimal reproduction, your Node.js version and the Kaelum version you are
using.

</details>
