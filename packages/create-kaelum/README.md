# create-kaelum

Scaffold a new [Kaelum](https://github.com/kaelumjs/kaelum) project.

```bash
npm create kaelum@latest
```

Pass a name and a template to skip the questions:

```bash
npm create kaelum@latest my-api -- --template ts-api
```

## Templates

| Template | Description                                    |
| :------- | :--------------------------------------------- |
| `js-web` | JavaScript, MVC with views and static files    |
| `js-api` | JavaScript, REST API                           |
| `ts-web` | TypeScript, MVC with views and static files    |
| `ts-api` | TypeScript, REST API                           |

## Options

| Option                  | Description                                   |
| :---------------------- | :-------------------------------------------- |
| `-t, --template <name>` | Template to use                               |
| `--install`             | Install dependencies without asking           |
| `--no-install`          | Skip installing dependencies without asking   |
| `-h, --help`            | Show help                                     |
| `-v, --version`         | Show the installed version                    |
